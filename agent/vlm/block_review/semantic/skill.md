# Skill：语义结构评估步骤

1. **定位路带**：先在第 1 张局部 RGB 找中心附近约 10 m 的道路或可通行地面。遇到树荫或树冠遮挡，检查两端和缝隙中露出的路面、路缘、车道入口及沿路排列的地物。需要时用第 3 张黄框外的影像确认走向和接续。区分直接可见和有依据的推断，按 Rule 填写 `drivable_check`。
2. **核对数据**：第 2 张是与第 1 张对齐的自动分割标签。检查深灰缺失和明显错位，填写 `data_check`。能定位的错分可以作为匹配证据。第 3 张的浅色来自叠加，不能用来估算类别占比或置信度。
3. **查同位置对应**：在路带前、中、后选择可定位的位置，尽量涵盖露出段和遮挡段。逐项填 `road_comparisons`，记录位置、RGB 路带依据和同位置道路标签状态。再用第 2 张判断类别占优、道路边界和道路标签是否明显变窄、截断或缺失。被覆盖段的标签缺失只说明语义路带受损，地面是否真有植被仍需 RGB 证据。
4. **查沿路区分度**：用第 1 张判断道路几何，在第 2 张比较至少两处道路两侧的类别、边界和相对排列。在 `degradation_check.evidence` 记录比较位置、各处布局，以及重复、变化或证据不足。单凭颜色相同或同样缺少道路标签不足以确认重复。
5. **输出判断**：逐图写 `observations`，按 Rule 填各字段的置信度与 `uncertainty`。在 `verdict.reason` 中写明支持结论的对照位置及其对匹配的影响。缺少关键对照时说明缺的是哪一处。

6. **核对后再提交结论**：引用 `road_comparisons` 中已记录的位置和标签状态。单类占优导致退化时，同时引用已记录的边界受损证据。纵向退化须先在 `longitudinal_comparisons` 分别记录两处布局。 先填 `verdict.evidence_refs`，编号按 Rule。 `verdict.reason` 只能引用前面已记录、能在图中定位的证据。保留“直接可见”“有依据的推断”和“无法判断”的区别；不补写未观察到的地物、数值或车端 BEV 内容。证据互相矛盾或关键证据不足，且其余证据无法独立满足 Rule 时，选「证据不足」并说明缺项。
