# Skill：高程退化逐档观察步骤

1. **定位**：找到十字和各档框线，确认哪个框对应哪个尺寸；标记不是高度结构。用内框定位新增环带。
2. **逐档执行**：只处理图像说明列出的有效扩展档位，由小到大，每档独立完成下列步骤。
3. **新增环带 `new_ring`**：只看当前框与上一框之间的区域，描述 RGB 地物及对应高度颜色，说明出现了什么、延续了什么。
4. **数据质量 `data_check`**：检查当前窗口内白色无数据是否遮住关键区域、两图是否明显错位。写“疑似”异常及依据；少量外围缺失不必使整个窗口不可判断。填写 `data_confidence`。
5. **当前窗口结构 `height_check`**：看整个当前框内，不只看环带。对照 RGB 与同位置高度颜色；先读出路面颜色，颜色明显比路面更靠近色带高端（绿色、亮黄色）的才是明显高出结构，建筑或植被外观本身不证明高出。深紫或亮黄端点同色可能来自饱和，不能用来证明同高、平坦或重复。`relief` 描述图示起伏，`raised_structure` 描述明显高出结构是否清晰，`height_distinctiveness` 判断明显高出结构在整个当前窗口内、可通行区域周围的面积和分布是否充分。清晰与充分是不同判断，“清晰”可以同时对应“低”；`raised_structure=无明显高出结构` 时 `height_distinctiveness` 不能选“高”。
6. **纵向结构**：根据 RGB 判断当前窗口的 `road_geometry`；在高度图上沿道路方向比较两侧高度颜色、轮廓、间距和分布，填写 `longitudinal_structure`。只有沿路持续相似才选“重复”；只比较一个横截面或只看两侧颜色相同不够。非线状区域二者同时选“不适用”；线状道路（含弯道）不选“不适用”。
7. **回答核心 Rule 的三个问题**：在每档的 `height_comparisons` 分别写整个当前窗口的路面与路侧高差、沿路对照及俯视遮挡证据。然后填写置信度：`raised_structure`、`height_distinctiveness`、`road_geometry`、`longitudinal_structure` 各填自己的 `<字段名>_confidence`，再写 `uncertainty`。
8. **档位结论**：根据整个当前窗口填写 `height_check.verdict.result` 和 `verdict.reason`。
9. **一句话证据 `evidence`**：说明新增范围出现了什么，以及它如何影响当前窗口的判断。例如“环带东侧出现一排亮黄色建筑，但只占窗口一角，周围高出结构仍稀少”。不要只重复规则。

少量新增结构须结合其在整个窗口中的面积、布局及与道路的关系。环带内结构属于当前窗口。
每档都要完成，是否停止由程序决定。所有文本字段用中文，每档单独描述，不复制上一档。

提交本档 `verdict` 前核对理由：只引用本档的 `height_comparisons` 和已填写的结构观察。每个明确结论的 `evidence_refs` 须引用本档新增环带 `new_ring`（N）和本档结构证据。纵向退化额外要求两处独立记录的沿路对照（A1、A2）。理由中的位置和现象必须已在本档记录，推断须保留不确定性。关键证据缺失或矛盾，且其余证据无法独立支持任何结论时，填「证据不足」并指出缺项。
