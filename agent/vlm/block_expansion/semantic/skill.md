# Skill：语义退化逐档观察步骤

1. **定位**：找到十字和各档框线，确认哪个框对应哪个尺寸；标记只用于定位。用内框定位新增环带。
2. **逐档执行**：只处理图像说明列出的有效扩展档位，由小到大，每档独立完成下列步骤。
3. **新增环带 `new_ring`**：只看当前框与上一框之间的区域，描述 RGB 地物及语义颜色分布，说明出现了什么、延续了什么。
4. **数据质量 `data_check`**：检查当前窗口内的无数据、低置信区域和两图错位。语义错分不自动等于数据不可用：能看清错分后的结构时仍可判断。关键结构看不清用 `不可用` / `不确定`。填写 `data_confidence`。
5. **当前窗口结构 `degradation_check`**：先沿 RGB 追踪路带，借露出路面、路缘和遮挡两端推断延续，再核对语义图同位置的道路是否完整、变窄、断开或缺失。在窗口证据中写「位置｜RGB 路带依据及可见性｜同位置语义道路状态」。优先核对新增环带上的道路，再结合整个当前框填写判断。区分可见路面错分与遮挡段语义道路缺失；树冠绿色不能证明地面植被侵入。
6. **纵向结构**：根据 RGB 判断当前窗口的道路几何。至少比较两个不同沿路位置的具体语义结构及相对路侧排列。连续绿色或相同的道路标签缺失不能单独证明重复；没有足够可比较位置时填「不确定」。非线状区域二者同时选「不适用」。
7. **逐字段置信度**：`dominance`、`road_boundary`、`road_intrusion`、`road_geometry`、`longitudinal_structure` 各填自己的 `<字段名>_confidence`，再写 `uncertainty`。
8. **一句话证据 `evidence`**：说明新增范围出现了什么，以及它如何影响当前窗口的判断。例如“上侧新增环带可见铺装路缘与内框道路接续，同位置道路标签被绿色分成两段，当前窗口的路带仍有断点”。不要只重复规则。

少量新增结构须结合其在整个窗口中的面积、布局及与道路的关系。环带内结构属于当前窗口。
每档都要完成，是否停止由程序决定。所有文本字段用中文，每档单独描述，不复制上一档。

先填 road_comparisons，再填 verdict。每条对照写位置、RGB 是直接可见还是推断延续、支持判断的图像线索，以及同位置语义道路状态。verdict.result 选退化、纵向退化、不退化或证据不足，reason 指出支持结论的对照位置和具体观察。有接续依据的遮挡段缺失道路标签可判退化。证据不足时明确指出缺少哪项对照。

提交本档 `verdict` 前核对理由：只引用本档的 `road_comparisons`、类别边界和沿路布局观察。每个明确结论的 `evidence_refs` 须引用本档新增环带 `new_ring`（N）和本档结构证据。纵向退化额外要求两处独立记录的沿路对照（A1、A2）。理由中的位置和现象必须已在本档记录，推断须保留不确定性。关键证据缺失或矛盾，且其余证据无法独立支持任何结论时，填「证据不足」并指出缺项。
