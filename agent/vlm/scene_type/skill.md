# Skill：整图道路结构判断步骤

1. **看全貌**：忽略纯黑无数据区域，看清有效区域内有哪些道路，住宅是否连片，路网是否覆盖地图大部分。
2. **看道路**：沿主要道路观察路面颜色、边界是否平直、宽度是否一致，是否连成规整网格。车道线看不清时不要写“无车道线”，也不要因此填“不确定”，改按路面和路网判断。
3. **填写观察字段**：`road_surface`、`road_layout`、`building_density`、`land_cover` 各按观察选择；确实看不清才选“不确定”。
4. **类型判断**：路网密集、路两侧连片住宅的选“结构化”；有车道线，或硬化路连成规整网格并覆盖地图大部分的选“结构化”（局部厂区路网或单条规整长路不算）；否则估计非结构化道路占道路总长的比例，约三分之一或以上选“非结构化”。厂房和零星房屋不决定类型。填写 `scene_type_confidence`。
5. **证据**：`evidence` 用一两句话写出最关键的可见依据；车道线实际看不清时要写明是按路面和路网推断的。混合地图写明两类道路各在哪里、大致占多少。
